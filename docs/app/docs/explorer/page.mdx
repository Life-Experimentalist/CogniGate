## 1. Edge Proxy Module (Go)

The edge proxy is designed for maximum speed and zero overhead:

- **`main.go`**: Launches a Fiber v2 server, connects to Redis, and registers the main chat completion endpoint (`POST /v1/chat/completions`).
- **`router.go`**: Implements active round-robin key rotation and circuit breaking. Inspects downstream HTTP status codes and excludes unhealthy keys from the rotation pool.
- **`redis.go`**: Launches a Redis connection pool. Spawns a background goroutine listening on the `cognigate:cache:invalidate` Pub/Sub channel to purge local memory caches.
- **`telemetry.go`**: Spawns an asynchronous worker queue that dispatches usage data to the domain engine without blocking the user response.

## 2. Domain Engine Module (Java)

The admin engine coordinates all state modifications, billing logic, and plugin execution:

- **JPA Entities (`entity/`)**:
    - `Tenant`: Manages isolated client environments and master bearer keys.
    - `ProviderKey`: Holds provider details and encrypted keys (AES-256-GCM).
    - `RoutingRule`: Defines primary models, fallback models, and prioritization.
    - `UsageMetric`: Captures token consumption audit records.
- **Core Services (`service/`)**:
    - `EncryptionService`: Performs AES-256-GCM encryption/decryption using `ENCRYPTION_MASTER_KEY`.
    - `CacheSyncService`: Serializes configurations into JSON and pushes them to Redis.
- **Plugin Manager (`plugin/`)**:
    - Uses the Janino compiler to compile uploaded raw Java code in-memory, loading it dynamically into custom classloaders for hot-swappable routing extensions.

## 3. Unified Configuration (YAML)

The [cognigate.config.yml](https://github.com/Life-Experimentalist/CogniGate/blob/main/cognigate.config.yml) file provides default values and schema documentation for all environment options, including database parameters, thread models (virtual threads enabled by default), billing schedules, and docs locations.
